# 互动效果第一版

工作台主导航「互动效果」打开 `#effects`。原 `#statistics` 的发布统计和定时报告仍可从页面右上角进入。

本机已有真实发送服务运行时，可先只更新独立只读统计服务（通常端口 8782），保留原发送进程。旧 API 服务遇到新页面接口尚未加载时，页面提供只读工作台入口；不自动重启发送进程。

## 页面与口径

- 默认最近 7 天，按实际平台发布时间、北京时间自然日筛选；支持今天、30 天、全部、自定义日期和「发布时间未知」。不使用计划时间替代实际发布时间。
- 支持平台、账号、任务、内容搜索和采集状态组合筛选。筛选、排序和分页保存在地址中，刷新、后退和详情关闭后可继续查看。
- 汇总是全部筛选结果的最新累计值，与当前分页无关。观看、点赞、回复各自显示覆盖条数；没有有效值时显示不可获取，有已采集零值时显示 0。
- 明细显示本条内容、账号、任务、发布时间、三项指标、相邻两次采集变化、采集状态和时间。可按发布时间、观看、点赞、回复或最近采集时间双向排序，缺失值始终排最后，同值按互动 ID 稳定排序。
- 详情侧栏显示完整正文、原文链接、指标切换曲线及采集历史。默认最近 100 次，可查看更多至最近 1000 次，明确显示历史总数。缺失样本保留空缺、曲线断开；约数不计算精确增量，真实下降保留负数。
- 导出为带 UTF-8 BOM 的 CSV，可用 Excel 打开，包含所有筛选结果及排序，不受当前页影响。时间带 +08:00，缺失指标留空，约数带「约」；正文保留换行、引号，并对公式型文字加前导单引号。
- 筛选日期表示这批内容的发布日期，数值表示截至最近采集的累计表现。相邻采集增量不是今日新增，也不代表每条内容拥有相同的比较时间段。
- 当前仍只有 X 和 Telegram 的既有采集能力；其他平台与不适用动作单独显示状态。平台回复计数与「他人直接回复」事件覆盖分开。

刷新数据、筛选、排序、查看历史和导出只读取本地已保存数据，不触发平台读取，不创建任务、尝试或执行作业，不改变停止、限额、回执或冻结清单。不修改数据库 schema。

## 只读接口

- `GET /api/engagement/effects`：筛选、汇总、分页、排序及平台／账号／任务选项。
- `GET /api/engagement/export`：同样筛选与排序下的全部 CSV 结果。
- `GET /api/engagement/items/{item_id}?limit=100`：完整展示条目、最近采集历史及历史总数；仅允许查看已核验真实发布条目。

列表参数：`platform`、`account_id`、`task_id`、`q`、`date_from`、`date_to`、`publication_time=all|unknown`、`status`、`sort=published_at|observed_at|views|likes|replies`、`direction=asc|desc`、`limit=1..100`、`offset`。
状态支持 `complete`、`partial`、`pending`、`failed`、`unavailable`、`not_applicable` 和 `stale`。导出不接受分页参数，也不截断结果。旧 `/api/engagement`、历史接口和 MCP 查询保持兼容。

## 验证

```sh
python -m unittest discover -s tests -p 'test_engagement*.py' -v
npm run test:ui:effects
```

浏览器验收启动临时数据库及关闭全部 worker 的独立服务，不读取真实账号或连接社交平台。覆盖日期筛选、组合筛选、跨页汇总、数值排序、详情与历史切换、查看更多、地址恢复、全量导出、公式处理、HTML 转义、空状态、未知发布时间、桌面／手机布局及旧报告入口，最后验证零发送尝试、零执行作业和全局停止保持开启。
结果和合成页面截图位于 `output/playwright/engagement-effects/`。
